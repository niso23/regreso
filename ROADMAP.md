# 🗺️ Roadmap de Regreso

Este documento refleja el estado real del desarrollo y hacia dónde va el proyecto. El orden de las secciones "Próximamente" e "Ideas futuras" puede cambiar según lo que aporte más valor a los jugadores.

## ✅ Completado

### Historia y contenido

- [x] **Prólogo** (3 niveles): la crisis de 2008, el descubrimiento del documento de Satoshi y los primeros satoshis.
- [x] **Mundo 1: *Descubriendo Bitcoin*** (4 niveles): qué es Bitcoin, por qué existe y por qué cambió la historia del dinero.
- [x] Secretos ocultos en los niveles.
- [x] Epílogo y resúmenes de nivel.

### Sistemas de juego

- [x] Motor narrativo por pasos (escenas, diálogos, decisiones, explicativos animados, revelaciones).
- [x] 10 minijuegos integrados en la historia.
- [x] Sistema de mundos con desbloqueo progresivo y mapa con mundos futuros.
- [x] Glosario interactivo con microniveles de aprendizaje (explicación + ejemplo + preguntas).
- [x] Mochila de objetos educativos.
- [x] Coleccionables: logos del ecosistema Bitcoin con su explicación.
- [x] Sistema de XP transversal (historia, glosario, colecciones, niveles perfectos, racha diaria).
- [x] Logros.
- [x] Guardado local automático, sin cuentas.
- [x] Sonido ambiental con control de silencio.
- [x] Botón de donaciones.
- [x] Despliegue web (Vercel).
